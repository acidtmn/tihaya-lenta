# Проверка версии 1.0.0

Проверено 9 октября 2026 года на двух чистых локальных установках без активных дополнительных плагинов.

| WordPress | PHP | Установка |
| --- | --- | --- |
| 7.0 | 8.2.31 | Подключены исходники темы |
| 6.6 | 8.3.31 | Готовый ZIP установлен штатным Theme Upgrader через WP-CLI |

## Результаты

- Установочный ZIP активируется на WordPress 6.6. Все 40 установленных файлов совпали с исходниками по SHA-256.
- В Chromium проверены мобильное вложенное меню, переходы, обычный и живой поиск, очистка подсказок, удержание и возврат фокуса диалогов, RSS, пагинация, статья, форма комментариев, копирование ссылки, защищённая паролем запись, пустой поиск и HTTP 404.
- На ширинах 320, 390, 768, 1100 и 1440 пикселей нет горизонтальной прокрутки. Снимки главной и статьи просмотрены.
- Статическая главная отображает своё содержимое и листает новости на обеих версиях WordPress. На WordPress 7.0 также проверены разделённое на страницы содержимое и отдельная страница записей.
- На WordPress 7.0 проверены собственный цвет и логотип, рубрика главного блока, количество карточек, отключение каналов, RSS, главного блока и кредита автора. Настройка числа новостей сохранена через интерфейс Customizer и проверена при новом открытии сайта.
- На WordPress 7.0 проверены пустой сайт, меню по умолчанию, простые постоянные ссылки, мобильное меню и обычный поиск с выключенным JavaScript.
- Архивы рубрики, метки, автора и RSS вернули HTTP 200.
- Все 29 PHP-файлов прошли `php -l`, все три JS-файла - `node --check`. POT создан через `wp i18n make-pot` без предупреждений.
- В проверенных браузерных сценариях нет ошибок JavaScript; на установке WordPress 6.6 нет PHP-ошибок в журнале.

## Пределы проверки

Браузерные проверки выполнены в Chromium. Safari, Firefox, сторонние плагины и все сочетания версий PHP/WordPress отдельно не проверялись. Проверена форма комментариев; отправка уведомлений через SMTP не проверялась. Тема не публиковалась в каталоге WordPress.org.

Для своего сайта проверь используемые плагины и материалы на тестовой установке до смены темы. Это особенно полезно при переносе оформления существующего издания.
