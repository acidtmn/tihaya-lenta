# Тихая лента 1.0.0

Первый бесплатный выпуск темы WordPress для новостных сайтов, городских медиа и авторских журналов.

## Что внутри

- Главные материалы, сетка публикаций и компактная лента «Сейчас».
- Статьи, страницы, рубрики, метки, авторы, поиск и комментарии.
- Мобильное вложенное меню, подсказки поиска и управление диалогами с клавиатуры.
- Настройки логотипа, цвета, главного блока, числа новостей, каналов и кредита автора.
- Стандартный WordPress без обязательных плагинов, счётчиков и внешних шрифтов.

**Автор:** [Кирилл Александров](https://kodalexandrova.ru). **Цена:** бесплатно. **Лицензия:** GPL-2.0-or-later.

## Скачать и установить

Скачай **tihaya-lenta-1.0.0.zip** из Assets этого релиза и загрузи его через **Внешний вид → Темы → Добавить новую тему → Загрузить тему**. Затем активируй тему и открой **Внешний вид → Настроить**.

Минимум: **WordPress 6.6, PHP 8.2**. Проверены WordPress 7.0 / PHP 8.2.31 и WordPress 6.6 / PHP 8.3.31. [Подробности проверки](https://github.com/acidtmn/tihaya-lenta/blob/v1.0.0/docs/testing.md).

В Assets также приложены файл SHA-256 и манифест. Автоматические архивы **Source code** предназначены для исходников; для установки выбирай подготовленный ZIP темы.

Демонстрационные публикации, база сайта и WordPress в архив не входят. [Инструкция и снимки](https://github.com/acidtmn/tihaya-lenta#readme).
