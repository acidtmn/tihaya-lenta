# Участие в разработке

Ошибки и предложения оставляй в [Issues](https://github.com/acidtmn/tihaya-lenta/issues). Для ошибки укажи версию темы, WordPress и PHP, браузер, шаги повторения, ожидаемый и фактический результат. Если проблема зависит от плагина, назови его и версию. Снимок экрана обычно помогает.

Не публикуй пароли, токены, личные данные посетителей и полный дамп сайта.

## Изменения кода

1. Сделай отдельную ветку и небольшую правку по одной задаче.
2. Сохраняй структуру темы: настройка и общие функции в `inc/`, шаблоны в корне и `template-parts/`, CSS и JS в `assets/`.
3. Используй стандартные API WordPress. Проверяй входные настройки и экранируй данные при выводе.
4. Проверь затронутый сценарий в WordPress, на узком экране и с клавиатуры. Для изменения JS проверь консоль браузера, для PHP - журнал ошибок.
5. Выполни `php -l` для изменённых PHP-файлов и `node --check` для изменённых JS-файлов в своём окружении.
6. Собери ZIP командой из README и проверь установку, если менялся комплект темы.
7. Открой pull request с описанием результата и выполненных проверок.

Новые строки интерфейса должны использовать текстовый домен `tihaya-lenta`. Шаблон переводов находится в `languages/tihaya-lenta.pot`; обновлять его можно командой WP-CLI `wp i18n make-pot . languages/tihaya-lenta.pot --domain=tihaya-lenta --exclude=docs,scripts,dist`.

Тестовые данные, WordPress, плагины и секреты не входят в этот репозиторий. Перед отправкой посмотри состав `git diff --cached`.
